# ¿Qué Queda?

Aplicación web para la gestión de productos e inventario compartido del hogar.

## Tecnologías utilizadas

- Frontend: Blazor WebAssembly y C#.
- Backend: Node.js.
- Base de datos: MariaDB.

## Estructura del proyecto

- `Components`: componentes de la aplicación.
- `Layout`: diseño y navegación.
- `Models`: modelos de datos.
- `Pages`: páginas del sistema.
- `Properties`: configuración.
- `Services`: servicios de la aplicación.
- `Shared`: componentes compartidos.
- `wwwroot`: archivos estáticos y estilos.

## Base de datos

El archivo `quequeda.sql` contiene la estructura de la base de datos.

## Descripción

El sistema permite administrar hogares, integrantes, productos, inventario, compras y consumos mediante una aplicación web.
